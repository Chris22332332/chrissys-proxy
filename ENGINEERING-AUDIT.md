Wisp server controls are documented upstream: TCP/UDP, port whitelist, stream limits, direct/private/loopback IP, forwarded-IP parsing, and Wisp version. See the official implementation docs at https://github.com/MercuryWorkshop/wisp-js.

## Proxy and network boundaries

ChrissysProxy uses one private authenticated Wisp endpoint with Libcurl/Epoxy as alternative transports. It does not include a list of arbitrary public proxies or mechanisms intended to evade school/work network filters or website controls. No proxy can be made "unbannable"; networks and websites control their own access policies.
